One funny line — a single sentence of at most 200 characters — for make.fun's "The One-Line Laugh" bounty. The program writes the line to `/output/entry.txt`.

The line plays on an everyday truth everyone recognises: buying a planner to get organised, then never opening it. The twist lands on the last word — the most organised thing in the narrator's life turns out to be the drawer the planner sits in, unopened.

## Run it

```sh
python3 main.py
```
